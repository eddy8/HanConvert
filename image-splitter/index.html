图片切割、九宫格、长图分页、海报打印

一张图，三种常见切法

图片分割就是把一张图片按网格、按高度或按纸张切成多张小图。本工具在切割前实时预览每条切线和编号，导出原始分辨率，不压缩、不加水印。

网格切图与九宫格

1–10 行 × 1–10 列任意组合，内置九宫格、四宫格、横向轮播等预设，可按 1:1、4:5、3:4 自动居中裁切或补边。

长截图智能分页

按 A4、手机屏幕、固定像素或段数切分，智能切线会在切割点附近寻找空白行，导出图片或一页一段的 A4 PDF。

大图分割打印成海报

选择 A4、A3 或 Letter 纸和横向页数，自动算出总页数、成品尺寸和打印 dpi，生成带裁切线、重叠区和页码的 PDF。

如何在线分割图片

  1. 选择、拖入或粘贴要切割的图片。
  2. 选择网格切图、长图分段或分割打印，再挑选预设或调整行列、比例、纸张。
  3. 在预览中检查切线、编号和成品尺寸，点击预览中的某一块可单独下载。
  4. 下载全部切图的 ZIP 或 PDF；手机上可用“分享 / 存到相册”一次保存全部图片。

图片分割常见问题

图片会上传到服务器吗？

不会。读取、切割、预览、打包 ZIP 和生成 PDF 都在当前浏览器中完成。首次下载 ZIP 或 PDF 时会联网加载开源的压缩与 PDF 组件，图片本身不会发送出去。

怎么把一张图片切成九宫格发朋友圈？

选择“九宫格 3×3”预设（默认 1:1 正方形并居中裁切），在预览中确认保留范围，点击“下载全部（ZIP）”。手机上可点“分享 / 存到相册”。发朋友圈时按文件名 01 到 09 的顺序选图，就能拼回完整画面。

Instagram 拼图为什么要倒着发？

Instagram 主页把最新的帖子放在左上角，所以要从右下角最后一张开始发。把“文件编号”设为“Instagram 发帖顺序”，按 post01、post02… 依次发布即可；每次发满整行（3 的倍数）才不会错位。

切出来的每张图为什么相差 1 像素？

当宽度或高度不能被行数、列数整除时，工具会把多出的像素平均分给各行各列，所以相邻两张最多相差 1 像素。所有小图拼回去正好是原图，不缺也不重复任何像素。

怎么把长图、长截图切成 A4 并转成 PDF？

切换到“长图分段”，每段长度选“按 A4 纸比例”，保持“智能避开文字”开启，再点“下载 PDF”。每段占一页 A4，切线会尽量落在文字之间的空白行，不会把一行字切成上下两半。

怎么把一张图片分割成多张 A4 打印成海报？

切换到“分割打印”，选择纸张和方向，设置横向页数（例如 3 页），工具会自动算出需要几行，并显示成品尺寸和 dpi。下载 PDF 后用 100%（实际大小）打印，沿裁切线修边，按 A1、A2… 页码对齐重叠区粘贴。

打印出来模糊怎么办？

看结果区的 dpi 数值，建议不低于 150 dpi，低于 100 dpi 近看会明显模糊。可以减少横向页数、把 A3 改为 A4，或换一张分辨率更高的原图；放大打印不会凭空增加细节。

免费吗？有水印和数量限制吗？

完全免费，无需注册，导出的图片不加水印。为保证浏览器稳定，一次最多切 100 张、海报最多 64 页，单张图片不超过 50 MB 或 6400 万像素。

支持哪些格式？手机上能用吗？

支持 JPG、PNG、WebP、AVIF、BMP、GIF（取第一帧）等浏览器能打开的图片，可导出 PNG、JPG、ZIP 或 PDF。手机浏览器同样可用；支持系统分享的手机会显示“分享 / 存到相册”，可一次把全部切图存进相册。
