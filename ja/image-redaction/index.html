画像にモザイクをかける主な場面

スクリーンショットやチャット

ユーザー名、アイコン、注文番号、メール、顧客情報、アクセスキーなどを隠してから共有します。

身分証や書類の写真

証明書番号、住所、署名、カード情報を黒塗りします。重要書類ではぼかしより黒塗りが安全です。

写真やSNS投稿

通行人や子どもの顔、車のナンバー、表札、背景の位置情報につながる文字を隠します。

AI検出後に目視確認が必要な理由

傾き、反射、低画質、装飾文字、複雑な背景によって検出精度は変わります。自動検出は作業の補助であり、見落としがない保証ではありません。

保存前に画像全体を拡大し、四隅、反射、通知欄、背景の看板も確認してください。重要な文字は少し広めに黒塗りしてください。

オンラインで画像にモザイクをかける方法

  1. 加工する画像を選択、ドロップ、または貼り付けます。
  2. 範囲をドラッグで囲むかブラシで塗るか、AI検出を実行して候補を確認します。
  3. 黒塗り、モザイク、ぼかしを選び、範囲と強さを調整します。
  4. 元画像と比較して見落としを確認し、保存するか「画像をコピー」でチャットに貼り付けます。

画像モザイク加工のよくある質問

画像はサーバーに送信されますか？

送信されません。画像の読み込み、編集、顔検出、OCR、保存はブラウザ内で行い、通信は初回のAIモデル取得だけに使います。

モザイクやぼかしは元に戻されますか？

塗りつぶしは元の画素を上書きするため復元できません。文字に使ったモザイクやぼかしは、ブロックが細かく文字が大きいほど推測や復元のおそれがあります。マイナンバーやカード番号、パスワードなどは塗りつぶしで少し広めに覆ってください。保存される画像は新しく描き直した1枚の画像で、元の画素や編集レイヤーは含みません。

ブラシでなぞってモザイクをかけられますか？

できます。ツールを「ブラシ」に切り替えて太さを決め、ドラッグすると髪や手書きのサイン、不規則な形に沿ってモザイクをかけられます。塗りつぶし・モザイク・ぼかしのいずれも使え、間違えたら元に戻すか、選択して移動・削除できます。

AIは何を検出できますか？

顔、電話番号、メール、ID、カード番号、URL、IP、ナンバープレート、氏名・住所ラベルを含む文字行を候補として表示します。必ず確認してください。

保存後の画像に位置情報は残りますか？

CanvasでJPG、PNG、WebPを新しく生成するため、通常は元画像のEXIF、GPS、端末名、撮影日時をコピーしません。

スクリーンショットにモザイクをかけるには？

スクリーンショットを撮ってこのページで Ctrl / Cmd + V で貼り付け、枠を描くかAI検出で電話番号やアイコンを見つけます。加工後に「画像をコピー」を押せば、そのままLINEやメールに貼り付けられます。

スマホで写真にモザイクをかけられますか？

できます。スマホのブラウザでこのページを開き、写真を選んで指で範囲をなぞり、保存するだけです。アプリのインストールは不要です。

無料ですか？透かしは入りますか？

無料で登録不要です。保存した画像に透かしは入らず、回数制限もありません。

どの画像形式とサイズに対応していますか？

JPG、PNG、WebP、AVIF、BMP などブラウザで開ける画像で、1枚30 MBまでです。2,400万画素または長辺6,000ピクセルを超える画像は縮小して処理します。PNG、JPG、WebPで保存できます。
