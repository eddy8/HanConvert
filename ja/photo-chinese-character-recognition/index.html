中国語画像OCR・画像テキスト化

写真から中国語テキストを抽出し、漢字を検索

中国語画像OCRは、写真やスクリーンショットに写った中国語の漢字をコピーできるテキストに変換する機能です。このページでは撮影・アップロード・貼り付けのあと認識ボタンを押すと通常数秒で結果が返り、ピンイン表示や1文字ずつの筆順検索もできます。書籍、メニュー、看板、学習プリント、SNSのスクショなど、中国語の画像から文字起こししたいときに使えます。

撮影・アップロード・貼り付け

スマートフォンではカメラや写真ライブラリを開けます。パソコンではファイル選択、プレビューへのドラッグ、Ctrl+V（Macは⌘V）でのスクショ貼り付けに対応します。

認識結果にピンインを表示

「ピンインを表示」をオンにすると、各漢字の上に声調付きピンインが付きます。多音字は語に合わせて判定され、重要は zhòng、重庆は chóng と表示されます。

漢字を選んで検索

結果の漢字を選ぶと中国語ピンイン、画数、Unicodeを表示し、筆順アニメーションや構成検索へ進めます。

写真から中国語漢字を認識する方法

  1. 漢字を撮影するか画像を選びます。パソコンでは画像をドラッグするか、Ctrl+V でスクショを貼り付けることもできます。
  2. 自動トリミングされたプレビューを確認し、「画像の漢字を認識」を押すと通常数秒で結果が出ます。
  3. 全文やピンインをコピーしたり読み上げを聞いたりし、漢字を選んで筆順や字形構成を調べます。

中国語画像OCRのよくある質問

複数の漢字を一度に認識できますか？

はい。1文字、単語、複数行の画像に対応します。結果全体をコピーするほか、各漢字を選んで詳しく調べられます。

簡体字と繁体字に対応していますか？

一般的な簡体字・繁体字に対応します。ぼけ、装飾文字、反射、強い傾き、複雑な背景は認識精度を下げる場合があります。

画像認識はブラウザー内だけで行われますか？

いいえ。トリミングと圧縮はブラウザー内で行い、処理済み画像を JianFan.app OCR サービスへ送信して認識します。

手書き漢字検索との違いは？

このページは写真やスクリーンショットを読み取ります。手書き検索はマスに1画ずつ書いた筆跡から漢字候補を探します。

中国語の画像をテキスト化できますか？

はい。中国語画像OCRとして、写真、スクリーンショット、スキャン画像から簡体字・繁体字を抽出できます。結果全体をコピーするほか、漢字ごとの検索も可能です。

スクリーンショットを貼り付けて認識できますか？

はい。Windows の Win+Shift+S や Mac の Control+Shift+Command+4 でスクショを撮り、このページで Ctrl+V（Macは⌘V）を押すと読み込めます。画像ファイルをプレビューにドラッグすることもできます。

画像の中国語にピンインを付けられますか？

はい。認識後に「ピンインを表示」を押すと各漢字の上に声調付きピンインが表示され、「ピンインをコピー」でテキストとしてコピーできます。多音字は語に合わせて判定しますが、人名や珍しい語の読みは確認してください。

対応する画像形式とサイズは？

PNG、JPEG、WebP、HEIC、HEIF の24 MBまでの画像に対応します。送信前にブラウザーで余白を切り取り、必要に応じて長辺1600ピクセル以内・2 MB未満に圧縮します。

ぼやけた写真でうまく認識できないときは？

文字を画面いっぱいに写し、正面から均一な明るさで撮影してください。画面上の文字は撮影せずスクショにすると正確です。1文字だけ調べたい場合は大きく切り抜くか、手書き検索を使ってください。

無料ですか？登録は必要ですか？

無料で、登録は不要です。不正利用を防ぐため、短時間に多数のリクエストを送ると、しばらく待ってから再試行するよう表示されます。

認識した中国語を読み上げできますか？

はい。「読み上げ」を押すとブラウザーまたはOS標準の中国語（普通話）音声で全文を読み上げ、もう一度押すと止まります。漢字を選んで「この字を発音」を押すと1文字だけ聞けます。端末内の音声を優先し、オンライン音声しかない場合は読み上げる文字がブラウザー提供元の音声サービスへ送信されます。

OCRとは何の略ですか？

OCRは Optical Character Recognition（光学文字認識）の略で、画像に写った文字を読み取り、編集できるテキストに変換する技術です。このページは中国語の漢字に特化したWeb版OCRで、認識した簡体字・繁体字をコピーし、ピンインを付けて1文字ずつ調べられます。
