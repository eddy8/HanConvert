汉字转平假名与振假名常见问题

平假名转换和振假名有什么区别？

纯平假名会用读音替换汉字；振假名保留原来的汉字，并在汉字上方显示读音。

Ruby HTML 是什么？

Ruby 是网页显示注音的标准 HTML 标签。复制后可在支持 Ruby 的网页编辑器中显示汉字及其上方读音。

人名和地名的读音一定正确吗？

不一定。人名、地名、当字和作品名可能有特殊读法，自动结果应结合可靠资料确认。
