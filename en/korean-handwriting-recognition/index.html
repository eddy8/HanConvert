KOREAN HANDWRITING TO TEXT

Type Korean by drawing it, without a Korean keyboard

Korean handwriting input turns hand-drawn Hangul into text you can copy: draw one syllable such as 한, pick it from the candidates, add it to the text box, and repeat until the phrase is complete. The page recognizes the 2,350 common Hangul syllables and 51 single jamo locally, which covers K-drama lines, lyrics, signs and textbook Korean.

How to write Korean by hand

  1. Draw one Hangul syllable in the square, such as 한, with a finger, stylus or mouse.
  2. Candidates appear automatically; select the one that matches.
  3. Choose Add to text. The square clears so you can draw the next syllable.
  4. When you finish, choose Copy next to the text box and paste the Korean into a translator, search box or chat.

Candidates while you write

Recognition runs in a background thread after every stroke, so there is no button to press, and the exact stroke order is not required.

Write a whole phrase

Each selected syllable goes into the text box and the square clears, so you can copy a full Korean sentence you see.

Local first, online fallback

Common syllables are matched in the browser. Stroke coordinates are sent to an online recognition service only when nothing is found locally or you choose to try it.

Korean handwriting input questions

How do I type Korean by handwriting?

Draw one Hangul syllable, select it from the candidates, and choose Add to text. Repeat for each syllable, then choose Copy to paste the whole phrase anywhere. No Korean keyboard or input method is needed.

Which Korean characters can it recognize?

Local recognition covers the 2,350 common syllables of the Korean KS X 1001 standard and 51 single jamo such as ㄱ and ㅏ. For a rare syllable, choose Try online recognition, which supports all 11,172 Hangul syllables.

Must I use the correct stroke order?

Not exactly, but the usual order (top to bottom, left to right) with a large, centered syllable gives better candidates. For similar shapes such as 가 and 기, pick the right one from the list.

Can it translate handwritten Korean?

No. It turns handwriting into Korean text only. Copy the text box and paste it into a translator.

How is the romanization shown?

The selected syllable is romanized on its own with the Revised Romanization of Korean, for example 한 is han. Sound changes across syllables, such as 한국어 pronounced hangugeo, are not reflected.

Is my handwriting uploaded?

Not by default; common syllables are recognized in the browser. Stroke coordinates are sent to an online recognition service only when nothing is found locally or you choose Try online recognition. The text box content is never sent.

How is this different from Korean Hanja handwriting?

This page recognizes Hangul letters. To look up the reading and meaning of a Chinese character used in Korean (Hanja), use Korean Hanja handwriting.
