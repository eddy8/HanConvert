Random passwords for real-world account requirements

This random password generator draws each password uniformly from every combination that fits your rules, using your browser's cryptographically secure random numbers (Web Crypto). For everyday accounts, use at least 16 random characters or a passphrase of five or more words; NIST SP 800-63B-4 requires at least 15 characters when a password is the only sign-in factor. Paste a site's password rules to set the length and character types automatically. The default is 20 mixed characters; turn symbols off for an alphanumeric password.

Choose the character mix

Enable uppercase letters, lowercase letters, numbers and symbols independently. Every enabled type appears in each password, so a required category cannot be omitted by chance.

Control allowed symbols

Replace the symbol set with the punctuation a site accepts, or enter forbidden characters in the exclusion field. Exclusions apply to every enabled character type and are case-sensitive.

Generate a batch

Create up to 100 distinct passwords per batch. Copy individual rows, copy all rows or download a plain-text file with one password per line. Results remain in this page until cleared or replaced.

Memorable passphrases

Pick random words from the EFF 7,776-word list, joined by a separator, with optional capitals and a number. Five words plus a digit give about 70 bits of entropy and are far easier to type than random characters.

Paste password rules

Paste a sign-up hint such as “8-16 characters with an uppercase letter and a number”. The tool picks a length within the limit, enables the required character types and reads any list of allowed symbols.

How to generate a password

  1. Paste the site's password rules, or set the length, batch size and character types yourself. Switch to Memorable words for a passphrase.
  2. Customize symbols and exclusions, and optionally remove lookalikes or consecutive repeats.
  3. Generate and copy a password, then save it in your own password manager.

Password generator questions

Are my generated passwords saved or uploaded?

Generation runs in your browser. Passwords are not sent to a server or written to browser storage. Refreshing, leaving or clearing the page removes this page's results; copying or downloading places them in your clipboard or chosen file.

Does every selected character type appear?

Yes. This is always enforced. With all four types selected, each password contains at least one uppercase letter, lowercase letter, number and symbol. Impossible lengths or entirely excluded categories produce an error instead of silently changing your rules.

What do the lookalike and consecutive-repeat options exclude?

Lookalike filtering removes Il1O0o|. Consecutive-repeat filtering prevents adjacent identical characters such as aa or 11. It still allows the same character in separate positions and does not block ascending sequences such as abc or 123.

Do more restrictions make a stronger password?

Restrictions help meet website rules or make a password easier to transcribe, but reduce the available combinations. The combination-strength indicator reflects the number of valid random outputs. It is not a cracking-time estimate or a guarantee of account security.

Can I generate numeric passwords or use my own symbols?

Yes. Select only numbers for numeric strings, or use the custom-symbol field for a site's accepted punctuation. If too few unique combinations exist for a batch, increase the length or character pool, or request fewer passwords.

What should I do with a generated password?

Use a separate password for each account and save it in a trusted password manager. The TXT export is unencrypted and is not a password vault. Results are unique within one batch, but separate batches can theoretically produce the same password.

How long should a password be?

Use at least 16 random characters for everyday accounts. NIST SP 800-63B-4 requires at least 15 characters when a password is the only authentication factor and at least 8 when it is part of multi-factor authentication, and recommends allowing at least 64. A 16-character password from uppercase and lowercase letters, numbers and the 23 default symbols has about 6.3×10³⁰ possible combinations, or about 102 bits.

What is a passphrase, and is it secure?

A passphrase is several random words, such as Kiln-Capped6-Cornmeal-Stifling-Cycle. This tool draws words uniformly from the EFF 7,776-word list, about 12.9 bits per word: five words plus a digit give about 70 bits, and six words about 77 bits. Passphrases are easier to type on a phone, which suits master passwords and Wi-Fi keys.

How do I generate a password that meets a site's requirements?

Paste the requirement text from the sign-up page into “Paste the site's password rules”, for example “8-64 characters with at least one uppercase letter, one number and one symbol”. The tool sets a length within the allowed range (20 when the limit allows it), enables exactly the character types mentioned and uses any listed symbols. Check the detected rules under the field and adjust them if needed.

How do I generate a 6-digit PIN?

Click “6-digit PIN” in Quick settings, or select only Numbers and set the length to 6. Six digits allow only 1,000,000 combinations, so use them only for PINs with attempt limits, such as a bank card or a door lock, never as a website password.
