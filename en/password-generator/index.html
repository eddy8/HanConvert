Random passwords for real-world account requirements

Use this online password generator when creating an account, changing a login or preparing several initial passwords. Match the receiving site's length and character rules before generating. The default is 20 mixed characters; turn symbols off for an alphanumeric password.

Choose the character mix

Enable uppercase letters, lowercase letters, numbers and symbols independently. Every enabled type appears in each password, so a required category cannot be omitted by chance.

Control allowed symbols

Replace the symbol set with the punctuation a site accepts, or enter forbidden characters in the exclusion field. Exclusions apply to every enabled character type and are case-sensitive.

Generate a batch

Create up to 100 distinct passwords per batch. Copy individual rows, copy all rows or download a plain-text file with one password per line. Results remain in this page until cleared or replaced.

How to generate a password

  1. Set the password length and batch size, then choose the allowed character types.
  2. Customize symbols and exclusions, and optionally remove lookalikes or consecutive repeats.
  3. Generate and copy a password, then save it in your own password manager.

Password generator questions

Are my generated passwords saved or uploaded?

Generation runs in your browser. Passwords are not sent to a server or written to browser storage. Refreshing, leaving or clearing the page removes this page's results; copying or downloading places them in your clipboard or chosen file.

Does every selected character type appear?

Yes. This is always enforced. With all four types selected, each password contains at least one uppercase letter, lowercase letter, number and symbol. Impossible lengths or entirely excluded categories produce an error instead of silently changing your rules.

What do the lookalike and consecutive-repeat options exclude?

Lookalike filtering removes Il1O0o|. Consecutive-repeat filtering prevents adjacent identical characters such as aa or 11. It still allows the same character in separate positions and does not block ascending sequences such as abc or 123.

Do more restrictions make a stronger password?

Restrictions help meet website rules or make a password easier to transcribe, but reduce the available combinations. The combination-strength indicator reflects the number of valid random outputs. It is not a cracking-time estimate or a guarantee of account security.

Can I generate numeric passwords or use my own symbols?

Yes. Select only numbers for numeric strings, or use the custom-symbol field for a site's accepted punctuation. If too few unique combinations exist for a batch, increase the length or character pool, or request fewer passwords.

What should I do with a generated password?

Use a separate password for each account and save it in a trusted password manager. The TXT export is unencrypted and is not a password vault. Results are unique within one batch, but separate batches can theoretically produce the same password.
