사이트 규칙에 맞춰 랜덤 비밀번호 만들기

회원 가입, 로그인 비밀번호 변경, 여러 계정의 초기 비밀번호 발급에 사용할 수 있습니다. 먼저 이용할 사이트의 길이와 허용 문자를 확인하세요. 기본 설정은 문자와 숫자, 기호를 섞은 20자이며, 특수문자를 끄면 영문과 숫자로만 만들 수 있습니다.

문자 종류 조합

대문자·소문자·숫자·특수문자를 각각 선택할 수 있습니다. 선택한 종류가 모든 비밀번호에 하나 이상 들어가므로 필수 문자 종류가 우연히 빠지지 않습니다.

허용되는 특수문자 설정

사이트에서 허용하는 기호만 직접 입력하거나, 사용할 수 없는 문자를 제외란에 넣으세요. 제외 조건은 선택한 모든 문자 종류에 적용되며 대소문자를 구분합니다.

여러 개 생성과 복사

한 번에 최대 100개의 서로 다른 비밀번호를 만들 수 있습니다. 개별·전체 복사와 한 줄에 하나씩 담는 TXT 저장을 지원하며 결과는 현재 페이지에만 유지됩니다.

비밀번호 생성기 사용 방법

  1. 길이와 생성 개수를 정하고 허용되는 문자 종류를 선택하세요.
  2. 특수문자와 제외 문자를 설정하고 필요하면 유사 문자나 연속 중복을 제외하세요.
  3. 생성한 비밀번호를 복사한 뒤 사용하는 비밀번호 관리 도구에 저장하세요.

비밀번호 생성기 자주 묻는 질문

생성된 비밀번호는 저장되거나 전송되나요?

현재 브라우저에서 생성하며 서버에 전송하거나 브라우저 저장소에 기록하지 않습니다. 새로고침·페이지 이동·결과 지우기 후에는 기록을 제공하지 않습니다. 복사나 다운로드를 선택하면 클립보드 또는 파일에 결과가 남습니다.

선택한 문자 종류가 모두 포함되나요?

네. 네 종류를 선택하면 대문자·소문자·숫자·기호를 각각 하나 이상 포함합니다. 길이가 부족하거나 어떤 종류의 문자가 전부 제외되면 조건을 자동으로 바꾸지 않고 설정을 수정하도록 안내합니다.

유사 문자 제외와 연속 중복 제외는 어떻게 다른가요?

유사 문자 제외는 Il1O0o|를 제거합니다. 연속 중복 제외는 aa나 11처럼 같은 문자가 바로 이어지는 경우만 막습니다. 떨어진 위치에 같은 문자가 나오거나 abc·123 같은 순서가 나오는 것은 허용합니다.

제외 조건이 많으면 더 안전한가요?

제외 조건은 사이트 규칙과 입력 편의를 위한 설정이며 가능한 조합 수를 줄입니다. 조합 강도 표시는 조건에 맞는 랜덤 결과의 수를 기준으로 합니다. 실제 해독 시간이나 계정 보안을 보장하는 수치는 아닙니다.

숫자만 또는 원하는 특수문자로 만들 수 있나요?

네. 숫자만 선택하면 숫자 문자열을 만들고, 특수문자 입력란에서는 허용할 기호를 지정할 수 있습니다. 가능한 조합보다 생성 개수가 많으면 길이나 문자 종류를 늘리거나 개수를 줄여 주세요.

생성한 비밀번호는 어떻게 관리하나요?

계정마다 다른 비밀번호를 쓰고 사이트가 허용하는 충분한 길이로 설정한 뒤 신뢰할 수 있는 비밀번호 관리자에 저장하세요. TXT는 암호화되지 않습니다. 서로 다른 생성 작업 사이에는 같은 결과가 나올 가능성이 있습니다.
