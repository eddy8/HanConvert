圖片切割、九宮格、長圖分頁、海報列印

一張圖，三種常用切法

圖片分割就是把一張圖片依網格、依高度或依紙張切成多張小圖。本工具在切割前即時預覽每條切線與編號，匯出原始解析度，不壓縮、不加浮水印。

網格切圖與 IG 九宮格

1–10 列 × 1–10 欄任意組合，內建九宮格、四宮格、橫向輪播等預設，可依 1:1、4:5、3:4 自動置中裁切或補邊。

長截圖智慧分頁

依 A4、手機螢幕、固定像素或段數切分，智慧切線會在切割點附近尋找空白行，匯出圖片或一頁一段的 A4 PDF。

大圖分割列印成海報

選擇 A4、A3 或 Letter 紙與橫向頁數，自動算出總頁數、成品尺寸與列印 dpi，產生含裁切線、重疊區與頁碼的 PDF。

如何線上分割圖片

  1. 選擇、拖入或貼上要切割的圖片。
  2. 選擇網格切圖、長圖分段或分割列印，再挑選預設或調整行列、比例、紙張。
  3. 在預覽中檢查切線、編號與成品尺寸，點選預覽中的某一塊可單獨下載。
  4. 下載全部切圖的 ZIP 或 PDF；手機上可用「分享 / 存到相簿」一次儲存全部圖片。

圖片分割常見問題

圖片會上傳到伺服器嗎？

不會。讀取、切割、預覽、打包 ZIP 與產生 PDF 都在目前的瀏覽器完成。首次下載 ZIP 或 PDF 時會連線載入開源的壓縮與 PDF 元件，圖片本身不會傳送出去。

怎麼把一張照片切成 IG 九宮格？

選擇「九宮格 3×3」預設，單張比例可改成 3:4 或 4:5 以配合 IG 主頁網格，在預覽中確認保留範圍後點「下載全部（ZIP）」。手機上可點「分享 / 存到相簿」，再依編號發文。

IG 九宮格為什麼要倒著發？

IG 主頁把最新的貼文放在左上角，所以要從右下角最後一張開始發。把「檔案編號」設為「IG 發文順序」，依 post01、post02… 依序發布即可；每次發滿整列（3 的倍數）才不會錯位。

切出來的每張圖為什麼相差 1 像素？

當寬度或高度無法被列數、欄數整除時，工具會把多出的像素平均分給各列各欄，所以相鄰兩張最多相差 1 像素。所有小圖拼回去正好是原圖，不缺也不重複任何像素。

怎麼把長圖、長截圖切成 A4 並轉成 PDF？

切換到「長圖分段」，每段長度選「依 A4 紙比例」，保持「智慧避開文字」開啟，再點「下載 PDF」。每段佔一頁 A4，切線會盡量落在文字之間的空白行，不會把一行字切成上下兩半。

怎麼把一張圖片分割成多張 A4 列印成海報？

切換到「分割列印」，選擇紙張與方向，設定橫向頁數（例如 3 頁），工具會自動算出需要幾列，並顯示成品尺寸與 dpi。下載 PDF 後以 100%（實際大小）列印，沿裁切線修邊，依 A1、A2… 頁碼對齊重疊區黏貼。

列印出來模糊怎麼辦？

看結果區的 dpi 數值，建議不低於 150 dpi，低於 100 dpi 近看會明顯模糊。可以減少橫向頁數、把 A3 改成 A4，或換一張解析度更高的原圖；放大列印不會憑空增加細節。

免費嗎？有浮水印和數量限制嗎？

完全免費，不需註冊，匯出的圖片不加浮水印。為維持瀏覽器穩定，一次最多切 100 張、海報最多 64 頁，單張圖片不超過 50 MB 或 6,400 萬像素。

支援哪些格式？手機能用嗎？

支援 JPG、PNG、WebP、AVIF、BMP、GIF（取第一格）等瀏覽器能開啟的圖片，可匯出 PNG、JPG、ZIP 或 PDF。手機瀏覽器同樣可用；支援系統分享的手機會顯示「分享 / 存到相簿」，可一次把全部切圖存進相簿。
